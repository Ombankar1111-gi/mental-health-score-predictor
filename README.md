# 🧠 Mental Health Score Predictor

An end-to-end Machine Learning web application that predicts a student's Mental Health Score based on lifestyle habits and social media usage.

---

## 📌 Project Overview

This project uses a trained Machine Learning model to estimate a student's mental health score using factors such as:

- Age
- Gender
- Country
- Academic Level
- Social Media Platform
- Daily Usage Hours
- Daily Unlocks
- Study Hours
- Physical Activity
- Sleep Duration
- Stress Level

The application provides an easy-to-use web interface where users enter their details and instantly receive a predicted mental health score.

## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/Ombankar1111-gi/mental-health-score-predictor.git
```

Go inside the folder

```bash
cd mental-health-score-predictor
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the FastAPI server

```bash
uvicorn main:app --reload
```

Open Frontend

```
index.html
```
